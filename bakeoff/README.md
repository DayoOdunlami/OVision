# Bake-off

A three-way design and build competition on this app. Round 1 is in progress.

| File | For | What |
|---|---|---|
| `BRIEF.md` | Studios | The brief. Start here. |
| `RULES.md` | Studios | Branches, sealing, gates, done signal. |
| `QA.md` | Studios | Every Gate 0 question and the client's answer. Part of the brief. |
| `REVIEW-TEMPLATE.md` | Studios | Used at Gate 2. |
| `entries/_TEMPLATE/` | Studios | Starter files; copy to `entries/<LETTER>/`. |
| `SCORING.md` | Client | Blind scoring sheet and the children's panel. |
| `KICKOFF.md` | Client | Messages to paste into each tool, gate by gate. |

Branches: `bakeoff/r1-base` (this), and one per entry: `bakeoff/r1-a`, `bakeoff/r1-b`,
`bakeoff/r1-c`. Nothing here touches `main`.
