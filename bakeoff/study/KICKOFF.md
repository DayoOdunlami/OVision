# Style study kickoff (for the client)

Start each tool in a new session on this repository, with the base branch set to
`bakeoff/study-base`. Decide privately which tool is S and which is T.

## S

```
You are studio S in a style study on this repository.
Check out bakeoff/study-base, then create and work only in a new branch called bakeoff/study-s.
Read bakeoff/study/BRIEF.md and bakeoff/study/RULES.md in full before doing anything else, then follow them.
Your letter is S, so your documents go in bakeoff/study/entries/S/.
Research before you invent, push as you go, and finish with DONE.md and a final commit with the message "bakeoff: study S ready".
Don't stop to ask me questions. Where something is unclear, make the call a world-class studio would make, note it in STUDY.md and carry on.
```

```

Keep your sprint 1 version reachable at ?v=1, put every change behind its own switch, and document each one in SPRINT-NOTES.md.
Push as you go, and finish with an updated DONE.md and a final commit with the message "bakeoff: study <your letter> sprint 2 ready".
```
