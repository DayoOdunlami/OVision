# Screens (study S)

All screens are from Chromium, running the page.
- **Phone:** 390 × 844.
- **Tablet:** 1180 × 820.
- **Day:** `h=11`. **Night:** `h=22`.

**Each dial step**
- On the scroll: `scroll-<step>-<size>-<day|night>`. The steps are paper, ink, wash and
  colour.
- In the pond: `pond-<step>-<size>-<day|night>`. Paper has no world, so it has no pond.
- Also: `scroll-ink-390-dawn-0645` (the 06:45 prayer, before sunrise) and
  `scroll-wash-1180-dusk`.

**Colour koi beside ink koi**
- `koi-colour-beside-ink-1180` and `koi-colour-beside-wash-390` show the same koi at the
  same instant, drawn twice (`?compare=1`).

**Recordings**
- `rec-into-the-pond-390.webm`: the scroll, touching the pond, the pond, and back.
- `rec-dial-and-vine-1180.webm`: Ink, then Ink and wash, then Colour, then Paper, back
  to Ink, then touching the trellis so the vine writes *Rooted*.

The recordings were made in headless Chromium while it recorded video, so they run a
little slower and less smoothly than the page itself.
