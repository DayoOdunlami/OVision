# Native motion evidence

The two `.webm` files are native recordings of the working tablet board, each containing at least 15 seconds after load, plus navigation. They are not assembled from stills. The pond clip includes the slow-water cache optimisation and precedes the final minimum-size guard and live preference fix; the original living skeletal fish code is unchanged. The cadence samples likewise precede those final two small fixes.

`cadence-without-video.json` separates the cost of recording from a final presentation-cadence probe at phone and tablet size. One case is explicitly marked invalid: an identical-fragment navigation retained a reduced-motion mount. The valid replacement is the earlier independent fresh-context phone Pond sample appended to the file. A subsequent fix makes the pond respond to live preference changes too.

This was a shared desktop software-rendered browser host, not physical Android. Other work may contend for CPU. The measured 10.5–21 fps normal cadence is a limitation, not a smoothness claim. The probe measures presentation opportunities, not the world's internal paint counter. Actual canvas pixel reads confirm movement in normal mode and zero changed pixels above a 2/255 RGB threshold in reduced mode at both sizes, for both worlds.
