# Scoring sheet (for the client)

Score each entry **1 to 5** on each line, by using it, not by reading about it. Use the
demo link first, then try it with your real family on the tablet if you can.

Two ways to break a tie: a line marked ★ counts double, and any entry that fails a
**gate** is out unless it's fixed.

## Gates (pass or fail)

- `npm run build` works and the preview loads on a phone and a tablet.
- The demo link fills it in, so every moment can be reached in a few minutes.
- Every moment 1 to 8 is either served or deliberately cut with a reason (1 and 2 can't
  be cut).
